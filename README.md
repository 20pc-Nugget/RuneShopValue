# Ali's Rune Shop Values
Shows what your runes are worth at Ali Morrisane's fixed shop buy prices:

Side panel: Every rune you're carrying, with its icon, stack quantity and gp value, plus a total.

In-game overlay: The same breakdown as a floating overlay that you can switch on or off.

Rune pouch support: Reads all rune pouch variants, so the runes inside your pouch are counted too.

Values use Ali Morrisane's static buy prices, not Grand Exchange prices, so they only change when the game changes them.
